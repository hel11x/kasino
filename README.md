# Casino Vltava

Webové kasino v čistém HTML, CSS a JavaScriptu (bez frameworků a bez buildu). Hraje se o herní žetony, žádné skutečné peníze.

## Hry
- **Ruleta**: evropské kolo s 37 políčky, animovaná kulička (běží proti směru kola, padá do přihrádky a poskakuje), plný sázecí stůl, historie čísel.
- **Blackjack**: blackjack 3:2, zdvojení, krupiér lízá do 17.
- **Sloty**: tři válce, tabulka výher.
- **Dostihy**: šest koní s kurzy, animovaný závod.

## Spuštění
Otevřete `index.html` v prohlížeči. Zůstatek se ukládá do `localStorage`.

## GitHub Pages
Settings → Pages → Branch `main`, složka `/ (root)`.

index.html, style.css, script.js, README.md
